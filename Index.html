Frequently asked questions

What to know before turning this preview into a live service.

Can this platform support both online printing and SaaS?

Yes. The planned product has a customer ordering side and a merchant subscription side, with a central admin area. They should share accounts and order data through a secure backend.

Will online payments work in this preview?

No. Real payments require a provider account, server-side order creation, signed webhook verification, refund handling, and secure configuration. Never store payment credentials in browser code.

Can a customer upload a PDF and print it automatically?

PDF upload and print routing need server-side file storage, malware and file checks, PDF page-count extraction, printer compatibility, and a secure local print agent or supported print service. This prototype only demonstrates the front-end flow.

Can each shop set its own rates?

That is part of the intended merchant dashboard. In production, rate settings must be stored per shop and validated on the server when an order is priced.
